# WAVE — музыкальный плеер для Telegram Mini Apps

Полноценный музыкальный плеер, встроенный в Telegram как Mini App: загрузка своей
музыки, альбомы, плейлисты, очередь воспроизведения, шафл/повтор и «Мне нравится» —
как в настоящем плеере, только внутри Telegram.

## Возможности

- **Своя библиотека.** Загрузка аудиофайлов (MP3, M4A, WAV, FLAC, OGG, AAC) прямо с
  устройства. Название, исполнитель, альбом, жанр и обложка определяются
  автоматически по тегам файла (ID3/MP4/Vorbis и т.д.), всё можно отредактировать.
- **Альбомы и плейлисты.** Группируйте треки как удобно, с собственной обложкой.
- **Полноценный плеер.** Мини-плеер и полноэкранный плеер, очередь воспроизведения,
  шафл, три режима повтора, свайп/перемотка, лайки.
- **Поиск.** Локальный поиск по своей библиотеке (треки, альбомы, плейлисты,
  жанры) и переход к поиску музыки через инлайн-ботов Telegram — приложение вызывает
  нативный `switchInlineQuery`, чтобы найти трек через любимого музыкального бота,
  после чего его можно сохранить и загрузить в свою библиотеку.
- **Работает офлайн.** Все файлы и метаданные хранятся локально на устройстве
  (IndexedDB) — ничего не уходит на сервер.
- **Тема Telegram.** Подхватывает тёмную/светлую тему, использует Back Button,
  Haptic Feedback и другие возможности Telegram WebApp API.

## Технологии

- React 19 + TypeScript + Vite
- Tailwind CSS v4
- Zustand (состояние библиотеки и плеера)
- IndexedDB (`idb-keyval`) — хранение аудио-файлов и метаданных на устройстве
- `music-metadata` — разбор тегов аудиофайлов в браузере
- Telegram WebApp JS SDK (`telegram-web-app.js`)

## Быстрый старт

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`. Внутри Telegram оно определит
`window.Telegram.WebApp` автоматически; в обычном браузере всё тоже работает —
Telegram-специфичные функции (тема, Back Button, haptics, `switchInlineQuery`)
просто отключены.

Сборка продакшен-версии:

```bash
npm run build
npm run preview
```

## Как подключить как Telegram Mini App

1. Задеплойте собранное приложение (`npm run build`, папка `dist/`) на любой
   HTTPS-хостинг (Vercel, Netlify, GitHub Pages, Cloudflare Pages и т.д.) — Telegram
   Mini Apps требуют HTTPS.
2. Создайте бота через [@BotFather](https://t.me/BotFather), если его ещё нет:
   `/newbot`.
3. Настройте Mini App для бота:
   - `/newapp` → выберите бота → укажите название, описание, картинку и **URL
     приложения** (ссылка на задеплоенный `dist/`).
   - Либо через `/mybots` → выбрать бота → **Bot Settings** → **Menu Button** →
     указать URL, чтобы приложение открывалось из кнопки меню чата с ботом.
4. Откройте бота в Telegram и запустите Mini App — все функции (тема, кнопка
   «Назад», вибро-отклик, `switchInlineQuery`) заработают автоматически внутри
   Telegram.

Подробнее в официальной документации:
[Telegram Mini Apps](https://core.telegram.org/bots/webapps).

## Структура проекта

```
src/
  components/
    common/       переиспользуемые UI-элементы (обложка, карточка трека, пустые состояния)
    layout/        каркас приложения (шапка, нижняя навигация)
    player/         мини-плеер, полноэкранный плеер, очередь
    sheets/         модальные окна (загрузка, создание альбома/плейлиста, действия с треком)
  screens/          экраны: Главная, Поиск, Моя музыка, Альбом, Плейлист
  store/            zustand-хранилища: library (библиотека), player (воспроизведение)
  lib/              работа с IndexedDB, метаданными файлов, Telegram WebApp API
  hooks/            аудио-движок, интеграция с Telegram
```

## Хранение данных

Аудиофайлы и метаданные (треки, альбомы, плейлисты) хранятся в IndexedDB прямо в
браузере/WebView устройства пользователя. Библиотека привязана к устройству —
между разными устройствами данные не синхронизируются (это сознательное
архитектурное решение: минимум инфраструктуры, полная приватность, работа офлайн).
